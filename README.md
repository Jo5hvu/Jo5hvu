## 🚀 Featured Projects

### 🔌 Smart Extension Plug

An IoT-enabled three-socket extension plug built using an ESP32-compatible Wemos D1 R32.

**Key features:**

* Independent control of three AC sockets
* Remote control through MQTT
* Real-time socket status
* Master ON/OFF controls
* Responsive web dashboard
* Automatic Wi-Fi reconnection
* Secure MQTT communication support
* Command and event logging

**Technologies:** ESP32 · MQTT · HTML · CSS · JavaScript · Relay Control

[View Repository](https://github.com/Jo5hvu/smart-extension-plug)

## 🧩 My Engineering Approach

```text
Understand the problem
        ↓
Break the system into functional blocks
        ↓
Measure and verify each stage
        ↓
Identify the root cause
        ↓
Implement and test improvements
        ↓
Document the final solution
```

I believe strong engineering is not only about making a system work. It is about understanding **why it works, why it fails, and how it can be improved**.
